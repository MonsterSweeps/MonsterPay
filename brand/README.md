# MonsterPay brand assets

Wordmark and mark, text converted to vector outlines — no font needed to render them.

## Files

| File | Use |
| --- | --- |
| `svg/monsterpay-dark-bg.svg` | Default. White "monster", violet "pay". For dark backgrounds. |
| `svg/monsterpay-light-bg.svg` | Ink "monster", violet "pay". For white and light backgrounds. |
| `svg/monsterpay-mono-black.svg` | Single colour. Print, fax, engraving, anything one-ink. |
| `svg/monsterpay-mono-white.svg` | Single colour, knocked out of a dark or photographic background. |
| `svg/mark-plate.svg` | Square mark on the brand plate. Profile pictures, app icons. |
| `svg/mark-transparent.svg` | Bars alone, no plate. Place over your own background. |
| `svg/favicon.svg` | Browser tab. |
| `png/` | Raster exports at 2x for anywhere SVG isn't accepted. |

## Colours

| Token | Hex | Use |
| --- | --- | --- |
| Violet | `#8331F9` | "pay", the speed bars, accents |
| Ink | `#15102A` | "monster" on light backgrounds |
| Ground | `#0E0228` | Brand background, mark plate |
| White | `#FFFFFF` | "monster" on dark backgrounds |

## Rules

- Clear space on all sides: the height of the "m". Nothing enters it.
- Minimum width: 90px on screen, 25mm in print. Below that use the mark alone.
- Never recolour, stretch, rotate, outline, add a shadow, or rebuild the lockup.
- Never set the wordmark in live text. Use these files.
- On a photograph or a busy background use `mono-white`, not the two-colour version.

## Note on the typeface

The letterforms are Inter Display SemiBold, the closest available match to the original
artwork — not an exact reproduction of it. If you have the source file or the original
font name, send it and these can be regenerated properly.
